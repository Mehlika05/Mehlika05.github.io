Code Log Guidelines

Code Logs is like web pages where students shows HTML and CSS topics. Every Code Log is created for create websites and use vs codes. Goal is clear teach the coding and create the websites for someone who just started to learn coading. It's explains and teaches, best choices for begginners.

Each Code Log has to have HTML file cod inside new the codelogs folder. The file names should follow a format such as index.html, index2.html. The title tag for the assignment title must also be used as the main title of the page. The information text should be a total of 150 words.

Students need to organize headings, lists, and text to view their work in an orderly manner. The text area tag helps us to clearly see the code. Once everything is complete, it should be saved to GitHub and uploaded to Canvas.
